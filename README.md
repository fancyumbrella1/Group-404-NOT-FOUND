# SCSE 26 — Plan and Develop

**Group:** 404 NOT FOUND

This project passes a robot navigation brief through three Qwen agents. Each
agent reads only its input artifact, validates its output, and saves the next
artifact. The final Python function is generated by Qwen and checked against
all 32 combinations of three obstacle flags and four goal directions.

| Stage | Input | Command | Output |
| --- | --- | --- | --- |
| Analyst | `brief.txt` | `python run_analyst.py` | `artifacts/requirements.json` |
| Planner | validated requirements JSON | `python run_planner.py` | `artifacts/plan.json` |
| Developer | validated plan JSON | `python run_developer.py` | `navigation_logic.py` |

## Run

Install [Ollama](https://ollama.com/), make the `qwen3:8b` model available,
and start its server. Install the Python dependency in a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
ollama pull qwen3:8b
```

With Ollama running at its default address, run the three scripts in order:

```powershell
python run_analyst.py
python run_planner.py
python run_developer.py
```

If Ollama runs at another address, set `OLLAMA_HOST` first. You can select a
different available model with `OLLAMA_MODEL`, although this assignment was
generated and checked with `qwen3:8b`.

Example of the generated navigation function:

```powershell
python -c "from navigation_logic import choose_action; print(choose_action(False, True, False, 'RIGHT'))"
```

This prints `RIGHT`. The three blocked arguments correspond to front, left,
and right. `goal_direction` may be `FORWARD`, `LEFT`, `RIGHT`, or `None`.
