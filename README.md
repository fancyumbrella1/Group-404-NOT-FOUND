# SCSE 26 — Plan and Develop

**Group:** 404 NOT FOUND

This project passes a robot navigation brief through three Qwen agents. Each
agent reads only its input artifact, validates its output, and saves the next
artifact. The final Python code is generated by Qwen and exposes
`decide_next_move(state)` as its public entry point.

| Stage | Input | Command | Output |
| --- | --- | --- | --- |
| Analyst | `brief.txt` | `python run_analyst.py` | `artifacts/requirements.json` |
| Planner | validated requirements JSON | `python run_planner.py` | `artifacts/plan.json` |
| Developer | validated plan JSON | `python run_developer.py` | `generated/navigation_logic.py` |

## Run

Install [Ollama](https://ollama.com/), make the `qwen3:8b` model available,
and start its server. Install the Python dependency in a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
ollama pull qwen3:8b
```

With Ollama running at its default address, run the three scripts in order:

```powershell
python run_analyst.py
python run_planner.py
python run_developer.py
```

If Ollama runs at another address, set `OLLAMA_HOST` first. You can select a
different available model with `OLLAMA_MODEL`, although this assignment was
generated and checked with `qwen3:8b`.

The Testing assignment uses the real Qwen model for three pipeline smoke tests,
then tests the generated function without a model call:

```powershell
python test_analyst.py
python test_planner.py
python test_developer.py
python test_generated_navigation_logic.py
```

The first three tests print their validated outputs and save them. The
Developer output is saved in `generated/navigation_logic.py` (the final
checklist location), `artifacts/navigation_logic.py` (the other location
mentioned in the assignment), and the original root `navigation_logic.py`.
Behavioural tests import only `decide_next_move` from `generated` and check
8 named scenarios plus all 64 combinations of the six sensor flags.

Example of calling the generated public function:

```powershell
python -c "from generated.navigation_logic import decide_next_move; print(decide_next_move({'goal_ahead': False, 'goal_on_left': False, 'goal_on_right': True, 'front_blocked': False, 'left_blocked': True, 'right_blocked': False}))"
```

This prints `RIGHT`. All six state fields are booleans. `choose_action` remains
inside the generated file as the original navigation helper, but callers use
`decide_next_move(state)`.
